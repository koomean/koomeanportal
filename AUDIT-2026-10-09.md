# Koo Mean Portal audit and release — 9 October 2026

Scope: `koomean/koomeanportal`, CNAME `koomean.com`, HTTPS. Goal: faster public entry, safer account lifecycle, complete responsive UI while keeping the IBM typefaces/orange theme/Portal layout. Chose a frontend-only release instead of changing the shared Worker or rebuilding in a framework; the required fixes are all in rendering and request scheduling.

## UI direction and motion

Core palette retained: dark base#14181d, panels#1b2027/#20262d, light base#f1f2f4, orange#d98a3d, primary text#eceef1. Light orange made darker for contrast. IBM Plex Sans Thai for content; IBM Plex Mono for small system metadata. Header → welcome hero → public link rail → search/filter/view tools → application grid remains unchanged. Compact rounded corners and quieter shadows replace giant fixed hero framing. Short dialog entrance/hero arrival and2px hover response; no per-card stagger. Reduced motion stops CSS animation and marquee, shows all public links statically. Video is optional regardless of motion preference.

## Remaining boundaries

1. No full backend penetration test or real-account admin write test. Shared Worker/D1/R2/routes/OAuth settings stay unchanged. Backend token signature/issuer/audience/expiry, authorization, input bounds and write-origin checks traced read-only.
2. GitHub Pages cannot enforce HTTP response protections through a meta tag: frame-ancestors, HSTS, Permissions-Policy and nosniff require a Portal-scoped edge response-header rule. Do not apply a zone-wide rule to unrelated sites.
3. Cloudflare can inject Analytics/JavaScript Detection scripts outside the artifact. Strict script policy blocks unlisted/inline edge scripts; report any production diagnostics honestly rather than weakening CSP. This can disable Cloudflare analytics/detection for this page.
4. The shared bootstrap includes unused public Blog/profile data; a future Portal-specific endpoint could reduce this, but was excluded to keep this release isolated from other websites. Public cache is5s and only an optimization; mutations and private responses are not browser-cached.
5. Future arbitrary remote app icons still load through img-src HTTPS; they cannot execute scripts in the page, but can disclose ordinary image request metadata. Registry/icons remain on-demand HTTPS third parties; owner should use trusted URLs.
6. Existing language preference translates the main catalog/status/auth UI; management/help copy is primarily Thai. This release does not claim a complete English localization or Safari/Firefox certification.
7. Reload requires fresh Google sign-in. In-memory tokens reduce persistence; this does not make the page immune to all XSS. Favorites intentionally retain app URLs locally.
