# Portal: a quieter, connected palette

Scope: `koomean.com`, repository `koomean/koomeanportal` only. Keep the header, hero, social rail, search/filter tools, application groups and settings in their current order. Preserve saved preferences, controlled background video, reduced motion, authentication and the shared maintenance state.

## Design direction before implementation

This is a personal directory of Koo Mean applications and links. The content and recognizable application logos should lead; the interface should support finding and opening them.

Dark palette: charcoal canvas `#14181d`, charcoal panel `#1b2027`, raised surface `#222a31`, soft text `#e3e8eb`, secondary text `#adb8c0`, steel accent `#9bb2c1`. Light palette: cool canvas `#f1f2f4`, paper panel `#fafbfc`, raised surface `#e8edf0`, ink `#29343e`, secondary text `#586773`, steel accent `#486b80`.

Keep the existing local IBM Plex Sans Thai for readable Thai and Latin text. Use the same family for supporting labels; reserve monospace for actual keyboard shortcuts. Remove the uppercase brand subtitle and the oversized generic welcome headline. The product name leads the hero; the description tells visitors what they can find here.

```
Brand                       Commands / Settings / Account
Home / Account
┌────────────────────────────────────────────────────────┐
│ Koo Mean                    subdued existing video     │
│ Portal                                                 │
│ Apps and links, with a clear description                │
│ Contact                              Playback control  │
└────────────────────────────────────────────────────────┘
Social links / same scrolling and pause controls
Search / group / view / refresh
Application groups and existing cards
```

Align content to the current left-hand baseline. Keep responsive layouts and card information hierarchy. Use restrained corner radii rather than the same pill shape everywhere. Neutral borders distinguish surfaces; accent color signals selection and keyboard focus. Keep application logos recognizable; remove decorative full-height colored card stripes. Retain group names and softly tinted group markers.

## Critique of the initial direction

A new slate canvas alone would still leave a generic card kit with bright blue outlines. Retain the familiar charcoal canvas instead, reduce saturation in the hero media, quiet the controls and cards together, remove the hero entrance/card lift decorations, and keep only the existing user-controlled video/social motion. This addresses the contrast across the whole page without replacing its structure or brand identity.
